🖼 附件与 OCR

通知的 .pdf / .doc / .docx / .xls / .xlsx / .ppt / 压缩包 会被自动下载到项目内的 data/attachments/ 并抽出正文与表格， 正文参与检索与回答。图片、扫描件里的文字需要 OCR —— 填百度智能云的 API Key / Secret Key（要开通「通用文字识别」）即可，不填则跳过图片文字。
命令行等价写法：python -m wayfinder ocr --api-key … --secret-key … ｜ 重新解析已有附件：python -m wayfinder attach --all

🔐 账号与登录

校内有一部分栏目在统一身份认证（CAS）后面。在这里填一次学号与密码， 之后抓取撞到登录墙会自动登录；登录页有图形验证码时，脚本会把验证码图下载下来交给 OCR 识别再填回去，认错就换一张重试。
凭据只落在本机 .auth/（已 gitignore、权限收紧到当前用户）， 不进 .env、不进日志、不发模型。 滑块 / 短信 / 双因子这类交互式验证脚本过不去，那种站点请用 Cookie 导入。
OCR 没认出这张验证码 —— 照着图填一次就能继续（不填也行，点「换一张」再让 OCR 试）：
命令行等价写法：python -m wayfinder login ｜ 不用密码（CAS 有滑块时用这个）：python -m wayfinder login --cookie ｜ 看当前会话：python -m wayfinder whoami
